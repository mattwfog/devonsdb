# Security policy

## Supported versions

The latest patch release in the `0.1.x` line is supported. Older patch
releases may be asked to upgrade before receiving a fix.

On-disk compatibility has a separate, stronger promise: every released v1
database remains readable as specified in [`docs/FORMAT.md`](docs/FORMAT.md).

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the
repository's **Security** tab and choose **Report a vulnerability** to open a
private GitHub security advisory with the maintainers. Include affected
versions, reproduction steps, impact, and any suggested mitigation.

If private vulnerability reporting is unavailable, contact the repository
owner through GitHub and ask for a private reporting channel without
including vulnerability details in the public message.
